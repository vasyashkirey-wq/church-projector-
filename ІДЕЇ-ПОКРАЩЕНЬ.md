- Резервне дублювання виходу (failover) на випадок, якщо монітор зникне
- Станції/пульт з телефону, ролі й паролі користувачів
- Кілька мов на екрані (другий/третій переклад) + 3 вбудовані переклади

- Автозапуск профілю за розкладом, автобекап, автооновлення через GitHub
- OBS-інтеграція + гід по NDI через OBS (прямий NDI неможливий — бібліотека
  для цього мертва, не наша провина)
- Пожертви/QR-генератор, H2R-титри, макроси/MIDI/OSC тригери
- Часткова локалізація панелі керування на CZ/EN

## 2. З порівняння з ProPresenter / EasyWorship / Proclaim

      прозвучали в ефірі, готовий звіт для щорічної CCLI-ліцензії (юридично
      важливо для церков, які показують текст пісень під авторським правом)

      куплет, але кожен музикант бачить транспоновано під свій інструмент
      (часткова основа вже є — «Акорди для музикантів» + транспонування)
- [x] 🔴 **AI-визначення біблійного вірша під час проповіді** — слухає
      мікрофон і сам пропонує вивести вірш, коли пастор його цитує (у
      ProPresenter це нова платна функція; складно і не 100% надійно).
      **У РОБОТІ (2026-08-29)**: без API-ключа — fuzzy-пошук локально по
      вже імпортованій Біблії (той самий механізм, що й у вкладці
      «Біблія»), без відправки звуку/тексту в інтернет.
- [ ] 🟡 **Спільна бібліотека пісень між кількома церквами** (як хмара
      Proclaim) — не плутати з наявним «резервна копія в хмару», це саме
      обмін піснями між різними інсталяціями програми
- [ ] 🔴 **Синхронізація з видаленим кампусом** — трансляція того самого
      «в ефірі» на інший фізичний майданчик церкви в реальному часі
- [x] 🟡 **Цифровий бюлетень служби на телефон прихожан** — той самий план
      служби, який бачить оператор, доступний гостям через QR (окремо від
      пульта керування — тільки перегляд, без керування). **ГОТОВО
      (2026-08-29)** — посилання (IP:порт/bulletin) показано під адресою
      пульта у вкладці «Станції», коли пульт запущено; QR під нього окремо

- [ ] 🔴 **Відео на кілька екранів як одна картинка** (відеостіна) — зараз
      кожен вихід показує РІЗНИЙ контент; тут навпаки — один ролик,
      розрізаний на частини між моніторами
- [ ] 🟢 **Показ коментарів/питань з YouTube/Zoom-чату на екрані** — для
      гібридних служінь із онлайн-аудиторією

## 4. Помічено під час рев'ю багів (2026-08-29)

Це не з порівняння з іншими програмами, а власні спостереження після
глибокого рев'ю коду цієї сесії — речі, які саме через це рев'ю стали
видно, але поки не чіпав, бо це вже не «баг», а «варто б».

- [х] 🟢 **Перевірити поріг автопропозиції вірша наживо** — зараз
      підібраний по одному ізольованому тесту без реальної проповіді.
      Після кількох служінь із увімкненою функцією — сказати мені, чи
      спрацьовує зайвий раз (підкручу менш чутливо) чи навпаки пропускає
      реальні цитати (підкручу чутливіше).
- [ ] 🟢 **Справжня дата для плану служби** — зараз немає поля вводу
      дати взагалі, тому бюлетень (щойно виправлено) підставляє
      «сьогодні» замість порожнього рядка. Можна додати вибір дати в
      плані служби наперед (плануєш у вівторок службу на неділю).
- [х] 🟡 **Автоматична самоперевірка словника перекладу** — оформити
      сьогоднішній ручний скан (пошук коротких слів словника, які
      «влазять» у довші реальні слова інтерфейсу) в окремий скрипт, що
      можна прогнати одразу після будь-якого додавання нових фраз —
      щоб такі баги ловились відразу, а не при окремому проханні
      перевірити. **ГОТОВО (2026-08-29)** — `npm run check-i18n`
      (окремо) і автоматично в кінці `npm test`.
- [х] 🔴 **Впорядкування коду зсередини** (не видно користувачу, лише
      полегшує МЕНІ вносити зміни безпечніше й швидше) — зараз більшість
      функцій живе в кількох файлах-«звалищах» по 2000-2700 рядків без
      чіткої структури. Розкласти по файлах-за-функцією зменшить ризик
      багів на кшталт щойно знайдених і пришвидшить майбутні правки.
      Це багатосесійна робота (орієнтовно 15-25 сесій), безпечна
      (поведінка програми не міняється, лише розклад файлів) — є вже
      готовий детальний план, можна почати в будь-який момент, коли
      скажеш.
