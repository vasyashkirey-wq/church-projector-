# Запуск на macOS

## Що змінилося в цій версії

1. **З'явилося меню застосунку.** Тепер на Mac працюють `Cmd+C`, `Cmd+V`,
   `Cmd+X`, `Cmd+A` у всіх полях вводу (пісні, Біблія, оголошення, PIN,
   назви виходів, налаштування), а також `Cmd+Q`, `Cmd+M`, `Cmd+H`.
   Раніше без меню ці клавіші на Mac не працювали взагалі.
2. **Конфіг збірки готовий до нотаризації** (hardened runtime + entitlements).
   Поки Apple-акаунта немає — застосунок збирається як непідписаний, і його
   можна запускати обхідним шляхом (нижче).

На Windows нічого не змінилося: смуга меню просто прихована (показати — `Alt`).

## Варіант А. Запустити непідписаний застосунок (безкоштовно, вже сьогодні)

Коли Mac качає `.dmg`/`.zip` з інтернету й застосунок не підписаний, macOS
покаже одне з двох:

- «Програму пошкоджено. Перемістити в кошик?»
- «Неможливо відкрити, бо розробника не перевірено.»

Це **не** означає, що застосунок справді зламаний — так macOS блокує все
непідписане. Обхід:

### Спосіб 1 — правою кнопкою (найпростіший)
1. Перетягни `Церква Проектор.app` у теку **Програми**.
2. Клікни на ньому **правою кнопкою** (або Ctrl+клік) → **Відкрити**.
3. У вікні натисни **Відкрити** ще раз.

Так треба зробити лише **один раз**. Далі запускається як завжди.

> На нових macOS (Sequoia/Sonoma) пункт «Відкрити» іноді сховано. Тоді
> відкрий **Системні налаштування → Конфіденційність і безпека**, прогорни
> вниз — там буде рядок про заблокований застосунок і кнопка **«Все одно
> відкрити»**.

### Спосіб 2 — через Термінал (якщо «пошкоджено» не зникає)
Ця команда знімає позначку «завантажено з інтернету»:

```
xattr -cr "/Applications/Церква Проектор.app"
```

Після неї застосунок відкривається звичайним подвійним кліком.

## Варіант Б. Справжній підпис + нотаризація (щоб не було жодних попереджень)

Потрібен платний **Apple Developer** акаунт (~99 $/рік). Тоді жодних обхідних
дій на комп'ютерах церкви не треба — застосунок відкривається одразу.

1. У Apple Developer створи сертифікат **Developer ID Application** і встанови
   його в Keychain на Mac, де збираєш.
2. Створи app-specific пароль на https://appleid.apple.com і задай змінні
   середовища перед збіркою:
   ```
   export APPLE_ID="твій@email"
   export APPLE_APP_SPECIFIC_PASSWORD="xxxx-xxxx-xxxx-xxxx"
   export APPLE_TEAM_ID="XXXXXXXXXX"
   ```
3. Додай у `package.json` у розділ `"mac"` рядок нотаризації:
   ```
   "notarize": { "teamId": "XXXXXXXXXX" }
   ```
4. Збирай як завжди: `npm run build-mac`.

Файл `build/entitlements.mac.plist` і `hardenedRuntime` уже налаштовані —
нотаризація без них не пройшла б.

---

## Збірка

```
npm run build-mac      # локальна збірка .dmg + .zip
npm run publish-mac    # збірка + викладення релізу на GitHub
```

Готові файли з'являться в теці `dist/`.

> **Іконка (необов'язково):** зараз береться стандартна. Щоб поставити свою,
> поклади `build/icon.icns` (1024×1024) і додай у `package.json → mac` рядок
> `"icon": "build/icon.icns"`.
