# Конвертація форматів (FFmpeg + HEIC)

Тепер програма може автоматично конвертувати непідтримувані Chromium формати
у ті, що відтворюються: **MOV/MKV/AVI/WMV/FLV… → MP4**, **HEIC/HEIF → JPG**,
**FLAC/WMA/AAC/OPUS… → MP3**, **TIFF → PNG**.

## ⚠️ Один раз треба виконати

```bash
npm install
```

Це додасть дві залежності (вони вже прописані в `package.json`):
- **ffmpeg-static** — бінарник FFmpeg (для відео/аудіо);
- **heic-convert** — для айфонівських HEIC-фото.

Без `npm install` програма працює як раніше, але при виборі непідтримуваного
файлу покаже підказку «сконвертуй у MP4/JPG/MP3» замість автоконвертації.

## Як це працює

- Коли обираєш відео-фон (вкладки «Шари» і «Графіка»), файл із розширенням
  MOV/MKV/… **сам перекодовується в MP4** і кешується — наступного разу той
  самий файл береться з кешу миттєво.
- Кеш: `<userData>/media-cache` (напр. на Mac `~/Library/Application Support/Церква Проектор/media-cache`).
- Велике відео конвертується не миттєво — з'явиться «⏳ Конвертую…», зачекай.

## Що вже підключено

- ✅ Відео-фон у «Шари» (`loadBgVideo`)
- ✅ Відео-фон у «Графіка» (`loadGraphicsBgVideo`)

## Що можна підключити так само (за потреби)

- Відео-фон тексту (`loadTextBgVideo`), медіа-плеєр (`loadMediaFiles`),
  фото-фони й слайд-зображення (для HEIC).

Для цього в кожному лоадері шлях `f.path` треба пропустити через
`ensureSupportedMedia(f.path, function(convertedPath){ … })` — як зроблено в
двох підключених вище.

## Збірка (.exe / .dmg)

`package.json` уже містить `build.asarUnpack: ["node_modules/ffmpeg-static/**"]`,
щоб бінарник FFmpeg розпаковувався й був доступний у зібраному застосунку.

---

**Тестувати наживо треба в Electron у себе** — конвертацію не можна перевірити
без запуску (у середовищі складання немає FFmpeg і живого рендера).
