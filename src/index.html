ℹ️ Як користуватись
1. Підключи телефон і ПК до одного Wi-Fi
2. Натисни "Запустити сервер"
3. Відкрий адресу в браузері телефону
4. Керуй проектором з телефону:

Керування мережевими PTZ-камерами — рух, зум, фокус, пресети. Працює паралельно з джойстиком FEELWORLD (не рухайте одночасно).

⭐ Пресети (збережені позиції)
Клік по номеру — камера переходить у збережену позицію. «💾» — записати поточну позицію в цей номер (загальний план / кафедра / хор тощо). Цифри 1-9 на клавіатурі теж викликають пресет активної камери.
🎬 Сцени продакшену (камера + ATEM однією кнопкою)
Одна кнопка = камера стає в пресет + ATEM перемикає вхід із переходом. Напр. «Проповідь» = Камера 1, пресет 2, ATEM вхід 2.
