# Димова перевірка (smoke test)

Запускай **перед кожною збіркою** — займає секунду, ловить типові поломки
до того, як вони потраплять у неділю.

```
npm test
```
або напряму:
```
node tools/smoke-test.js
```

## Що перевіряє

1. **Синтаксис** — усі `.js` файли й кожен `<script>` в `index.html`.
2. **Кнопки** — кожен `onclick`/`onchange` викликає функцію, яка **існує**
   (ловить «кнопка нічого не робить»).
3. **Ініціалізація** — усі функції зі стартового списку існують
   (ловить «застосунок не запустився»).
4. **Навігація** — кожна вкладка має свій вміст, немає «мертвих» кнопок і
   дублікатів, жодну вкладку не втрачено.
5. **Імпорт Біблії** — назви книг (українською/російською/чеською/англійською)
   мапляться на правильні книги.
6. **Баланс тегів** — `<div>`, `<button>`, `<select>` відкрито = закрито.

## Як читати результат

- Зелено, «**УСЕ ДОБРЕ**», код виходу `0` → можна збирати.
- Червоно, «**ЗНАЙДЕНО ПРОБЛЕМИ**», код виходу `1` → полагодь, тоді збирай.

Код виходу `1` зручний для CI/скриптів: збірку можна автоматично зупиняти,
якщо тест не пройшов.

## Порада

Це «сітка безпеки» для наступного кроку — чистки дубльованого коду.
Роби зміну → `npm test` → якщо зелено, можна далі. Так рефакторинг стає
безпечним: будь-яка випадкова поломка спливе одразу.
