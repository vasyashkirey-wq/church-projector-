# Церква Проектор

Настільна програма для проєкціювання під час богослужінь — тексти пісень, вірші з Біблії, оголошення, титри для трансляції та керування кількома екранами. Створена для української баптистської церкви в Празі (Церква ЄХБ м. Прага).

Працює на **Windows** і **macOS**. Побудована на Electron.

---

## Можливості

**Вивід у зал**
- Тексти пісень і вірші з Біблії на проектор із гарним оформленням
- Імпорт пісень і перекладів Біблії з різних форматів (JSON, TXT, OpenLP, OpenSong, ProPresenter, USFM, OSIS, Zefania, CSV)
- Двомовний вивід (українською + чеською) одночасно
- Акорди й транспонування для музикантів (окремо від того, що бачить зал)
- Автопідбір розміру шрифту, стабільний розмір на всю пісню
- Розбиття довгих куплетів на кілька слайдів
- Порядок частин пісні (куплет → приспів → куплет…)

**До 4 виходів одночасно**
- Проектор у залі, трансляція, додаткові екрани
- Кожному виходу — свій вміст або дзеркало
- Хромакей (зелений фон) для OBS
- Маршрут «Графіка» — оформлений слайд на трансляцію, звичайний текст у зал

**Планування служби**
- Складання плану з пісень, віршів і пунктів (молитва, проповідь, пожертви)
- Проведення всієї служби однією кнопкою «Наступний»
- Збереження й перенесення планів

**Трансляція**
- Титри поверх живого відео (нижня третина): 6 стилів, 5 розташувань, 5 анімацій
- QR-екран: код із логотипом, фото з QR у кутку, кілька QR разом, або готове фото QR
- H2R-титри для нижньої третини

**Керування під час служби**
- Миттєвий чорний екран (клавіша B) із поверненням того самого вмісту
- Заморозка кадру, екран логотипа на паузі
- Швидкі закладки, скасування дій
- Таймер проповіді на екран сцени
- Центральна гучність відео + музики, приглушення для молитви
- Прев'ю «що зараз у залі»

**Кілька пристроїв**
- Другий комп'ютер як повна панель керування
- Телефони як пульти (через Wi-Fi, з PIN-захистом)
- HTTP API для Stream Deck / Bitfocus Companion

**Монітори**
- Показ номерів на екранах, тестова сітка для наведення проектора
- Прив'язка виходу до монітора, що переживає перезавантаження

**Надійність**
- Повна резервна копія всіх даних одним файлом + автобекап за розкладом
- Профілі служб (ранкова, вечірня, молодіжна) з автозапуском за розкладом
- Автооновлення через GitHub Releases
- Лог помилок для діагностики
- Кошик видалених пісень
- Мова панелі: українська / чеська / англійська

Плюс: інтеграція з OBS Studio та ATEM, шари екрана (відео-фон під текстом, оголошення поверх слайда, фонова музика), типографіка, анімації, статистика, імпорт PowerPoint.

## Встановлення (для користувачів)

Готові збірки — у розділі [Releases](https://github.com/vasyashkirey-wq/church-projector/releases):
- **Windows:** завантаж `.exe`, запусти, встанови.
- **macOS:** завантаж `.dmg`, перетягни в Програми. При першому запуску: правою кнопкою → «Відкрити» → «Відкрити» (додаток не підписаний сертифікатом Apple).

Усі пристрої мають бути в одній Wi-Fi мережі. При першому запуску Windows може попросити дозволити доступ у приватній мережі — погодься.

## Збірка з коду (для розробників)

Потрібен [Node.js](https://nodejs.org) LTS.

```bash
npm install          # встановити залежності
npm start            # запустити в режимі розробки
npm run build-win    # зібрати .exe (Windows)
npm run build-mac    # зібрати .dmg (macOS)
```

Публікація нової версії з автооновленням описана в [АВТООНОВЛЕННЯ-GitHub.md](АВТООНОВЛЕННЯ-GitHub.md).

## Структура

```
main.js                  головний процес Electron (вікна, сервери, IPC)
src/
  index.html             панель керування (Біблія, пісні, теми)
  extras.js              більшість вкладок і логіки
  formats.js             парсери форматів пісень і Біблії
  preload.js             міст між панеллю й системою
  projector.html         вікно виводу
  projector-preload.js   рендер на екрані виводу
```

---

## Технічно

- Electron 28, без зовнішнього фреймворку — чистий JS
- Локальне зберігання (нічого не йде в хмару без згоди)
- Пульт: WebSocket (порт 3939) + HTTP API
- Синхронізація двох ПК: WebSocket (порт 4242)
