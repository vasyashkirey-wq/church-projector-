# Автооновлення через GitHub — покрокова інструкція

Мета: щоб програма сама перевіряла нову версію й пропонувала оновитись.
Це разове налаштування. Далі кожна нова версія публікується однією командою.

---

## Крок 1. Створити акаунт GitHub (якщо немає)

1. Відкрий https://github.com → **Sign up**.
2. Введи пошту, пароль, придумай ім'я користувача (напр. `sobraniepraha`).
   Це ім'я знадобиться далі — запам'ятай його.
3. Підтверди пошту.

Акаунт безкоштовний. Публічні репозиторії й Releases теж безкоштовні.

---

## Крок 2. Створити репозиторій

1. Угорі праворуч натисни **+** → **New repository**.
2. **Repository name:** `church-projector`
3. Тип: **Public** (для автооновлення так найпростіше; приватний теж можна, але потрібен токен — див. нижче).
4. Нічого більше не заповнюй, натисни **Create repository**.

Тепер у тебе є адреса виду:
`https://github.com/vasyashkirey-wq/church-projector`

---

## Крок 3. Вписати своє ім'я у програму

У файлі `package.json` знайди блок `publish` і заміни `vasyashkirey-wq`
на своє ім'я користувача GitHub (у двох місцях — `publish` і `repository`):

```json
"publish": [
  {
    "provider": "github",
    "owner": "ТВОЄ_ІМ'Я",        ← сюди
    "repo": "church-projector"
  }
]
```

Збережи файл.

---

## Крок 4. Створити токен доступу (щоб публікувати)

1. GitHub → праворуч угорі твоє фото → **Settings**.
2. Внизу зліва **Developer settings**.
3. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**.
4. **Note:** напиши `church-app`.
5. **Expiration:** обери «No expiration» (або 1 рік).
6. Постав галочку **repo** (це дасть право заливати релізи).
7. Внизу **Generate token**.
8. **СКОПІЮЙ токен одразу** — він показується лише раз. Це рядок виду `ghp_xxxxxxxx`.

Токен — це як пароль. Нікому не показуй і не клади в код.

---

## Крок 5. Опублікувати першу версію

На комп'ютері, де збираєш програму, відкрий термінал у теці програми
і встав токен у змінну середовища (одноразово на сеанс):

**Windows (PowerShell):**
```powershell
$env:GH_TOKEN="сюди_встав_токен"
npm install
npm run publish-win
```

**Mac (термінал):**
```bash
export GH_TOKEN="сюди_встав_токен"
npm install
npm run publish-mac
```

Що відбудеться: програма збереться і сама заллється в розділ **Releases**
твого репозиторію на GitHub. Перевір: відкрий
`https://github.com/vasyashkirey-wq/church-projector/releases` — там має з'явитись версія.

---

## Крок 6. Далі — кожна нова версія

1. Виправив/додав щось у програмі.
2. У `package.json` підніми номер версії, напр. `"version": "1.0.1"` → `"1.0.2"`.
   **Це обов'язково** — updater порівнює саме номер.
3. Знову: `npm run publish-win` (або `publish-mac`).

Усе. Церковний комп'ютер за 5 секунд після запуску побачить нову версію,
тихо завантажить і запитає «Встановити зараз?».

---

## Приватний репозиторій (якщо не хочеш публічний)

Автооновлення з приватного репозиторію теж працює, але кожен церковний ПК
має знати токен. Це складніше й менш безпечно. Порада: **лиши репозиторій
публічним** — там лежить лише зібрана програма, нічого таємного (пісні й
налаштування зберігаються локально на ПК, не в репозиторії).

---

## Часті питання

**Чи побачать люди мій код?**
У публічному репозиторії — так, але туди заливається лише *зібрана* програма
(файли релізу), а не вихідний код, якщо ти сам його не додаси.

**Скільки коштує?**
Нічого. GitHub Releases безкоштовні.

**Що як не хочу морочитись із GitHub?**
Тоді просто продовжуй ставити нову версію вручну на кожен ПК — автооновлення
не обов'язкове, решта програми працює й без нього.
